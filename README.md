# Ballon-Pop-Game
Balloon Pop Game is a simple interactive game where the player pops balloon by clicking on them. The game is designed to be fun and easy to play while practicing basic programming concepts in Scratch.
**Features**
1.Interactive balloons
2.Click based gameplay
3.Score based game
4.Simple and beginner friendly controls
5.Fun and interactive design.
**Technologies Used**
Scratch
Scratch blocks
**Concepts Used**
Events
Sprites
Variables
Loops
Conditions
User interaction
**How to Play**
1.Start the game.
2.Click on the ballons
3.Pop the balloons to increase your score.
4.Try to achieve the highest score possible.
**Project Purpose**
The project was created to practice programming logic and understand basic game development concepts using Scratch.
